# The 2025 restart lessons

These three lessons were written during the October 2025 restart, when the
application repository was reset to a README and a changelog. They are cleaner
than the 2023 originals in `../original-lessons/`, and they have the same
disqualifying problem: **they describe an application that was never built.**

- `01-setting-up.md` — a Phoenix 1.7 project that was never generated
- `02-user-authentication.md` — a Pow configuration that was never applied
- `03-forum-functionality.md` — labelled "INCOMPLETE - PLANNED" in its own title

They are kept because the failure they represent is the one this project keeps
making, and it is worth being able to point at. Writing the lesson first and
the code later produces confident, well-formatted prose about software that
does not exist, and nothing in the process ever notices.

The rule that replaced them is in `../../../STATUS.md`: a lesson ships when the
code it describes is merged and tested, and not before.
